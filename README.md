# Thai PromptPay QR Code Generator

## How it looks like
Run it by pressing [here](https://ayechanaungthwin.github.io/prompt-pay-qr-code-generator).

## Features
- Generate (and download) a Thai PromptPay QR code from a phone number and optional amount.
- **Payment slip verification**: upload a bank payment slip image; the mini QR code on the slip is decoded in the browser and can be verified against the bank network via the [SlipVerify API](https://github.com/xNearbyTeam/Slip-Verify). A free API token is available from their [Discord community](https://discord.gg/VMr2pqukDX).
